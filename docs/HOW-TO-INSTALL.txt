ESPN NFL 2K5 (native PC) - version 0.8.1
=======================================

You need: Windows 10 or 11 (64-bit), a graphics card from the last ~8 years,
and your own copy of ESPN NFL 2K5 for the original Xbox (USA version).
No game files are included or downloaded.

Use a CLEAN dump of your own retail disc: an .iso/.xiso you made from the
disc, or the extracted disc folder (the one with default.xbe and a
vc_53450030 folder in it). A disc image that already has a mod patched into it
(for example a SOFTDRINK ISO) is not accepted as the game source. Install the
game from the clean dump, then add mods with their .2k5patch file (below).


INSTALL
-------
1. Right-click the downloaded .zip and choose "Extract All...". Extract it
   somewhere you can write to: Desktop, Documents, D:\Games ...
   NOT C:\Program Files, and do not start the game from inside the .zip.
2. Open the extracted NFL2K5-PC-0.8.1 folder and double-click NFL2K5.exe.
   If Windows SmartScreen says "Windows protected your PC", click
   "More info" then "Run anyway" (the build is not signed).
3. The first time, the game asks for your disc:
   - If you have a disc image (.iso), click YES and choose it. The game
     unpacks it into the game folder by itself (a window shows the progress,
     a few minutes, about 8 GB of free space). Your .iso is not changed.
     Tip: an .iso placed in the game folder is found without asking.
   - If you already have the extracted disc folder, click NO: the game opens
     the folder it goes in (original\disc). Copy the CONTENTS of your
     extracted disc there, so that this file exists:
         NFL2K5-PC-0.8.1\original\disc\default.xbe
     Then start NFL2K5.exe again.
   You only do this once. Nothing else needs to be created by hand.


PLAYING
-------
- An Xbox, PlayStation (DualSense / DS4) or other controller is recommended;
  plug it in before starting. Keyboard works too.
- Settings: press F1 in game (or Back + Start on a controller), or
  Options > Video Settings in the game's own menu.
- Graphics API: F1 > Video > Graphics API: Direct3D 11 (default), Direct3D 12
  or Vulkan, used from the next start. If Direct3D 12 or Vulkan cannot show
  the game on your PC, the game says why, switches to Direct3D 11 and
  restarts by itself (no more black screen with sound).
- Display mode: Windowed, Borderless or Exclusive. Exclusive switches your
  screen to the chosen resolution; if your display has no such mode, the menu
  says "not available" and the game uses borderless.
- Frame rate: the game itself runs at up to 60 frames a second (that is how
  it was made), so Frame Rate Cap offers 30, 60 or Original. More than 60 on
  screen is only possible with Frame Generation (Direct3D 12, off by
  default), which inserts generated frames: up to 120 shown, game still 60.
- Render Scale is yours to set. With Dynamic Resolution on Auto the game may
  lower the resolution while the graphics card falls behind, but it never goes
  above the Render Scale you chose.
- Your own music: put songs in the Music folder. Each folder (sub-folders too)
  is a playlist; songs straight in Music play as a "Music" playlist. Any file
  names work. Then F1 > Music Player. A file the game cannot read is skipped
  and named in the log.
- To play the original game while a mod pack is selected, start it with
  --retail (for example a shortcut to "NFL2K5.exe --retail").


MOD PACKS (.2k5patch) - e.g. SOFTDRINK 2K28 v0.9
------------------------------------------------
SOFTDRINK v0.9 comes as two downloads. Use the regular one,
SOFTDRINK-2K28-v0.9.2k5patch (about 1.2 GB), not the "-64MB" one.
1. Drag the .2k5patch file onto NFL2K5.exe (or copy it into the game's
   mods\patches folder - it exists already).
2. Start the game (if it is not running). A few seconds after the menus
   appear it installs the pack in the background; a message shows the
   progress. It takes a few minutes and you can keep playing meanwhile.
   A pack copied in while the game runs is picked up too.
3. When it says the pack is installed and selected, quit and start the game
   again. The pack plays from then on.
Extras > Mods switches between installed packs (or back to the original
game); the game asks first and restarts itself.
You do NOT need extract-xiso or any other tool for a .2k5patch. Do not put a
patched ISO in mods\patches: use the .2k5patch.


MYCAREER HOME (WITH SOFTDRINK v0.9)
-----------------------------------
Game Modes > MyCareer, start a career, and you arrive in your apartment.
  Left stick / D-pad up-down      walk
  Right stick / D-pad left-right / LB RB    turn
  A    use what you are facing        Y    fixed views and back
  B    the Career Menu list
Front door: next game or practice. Phone: agent and coach calls. Mirror:
appearance and attributes. Computer: stats, schedule, bank, homes and the
Furniture Shop. TV: SOFTDRINK's Career Menu (Settings + Save > Save saves).
The furniture models are free CC0 assets: see mods\mycareer-home\CREDITS.txt.


SANDBOX (SEPARATE DOWNLOAD)
---------------------------
Sandbox is not part of this download; it ships as its own pack
(NFL2K5-Sandbox-pack-0.8.1). To add it, copy that pack's "mods" folder into
your game folder so this file exists:
       NFL2K5-PC-0.8.1\mods\sandbox\pack.json
Then start the game: Sandbox appears under Game Modes.


UPDATING FROM AN EARLIER VERSION
--------------------------------
Extract the new version over your game folder (or into a new folder and move
your "original", "saves", "Music" and "mods" folders across). Nothing of yours
is overwritten:
- Settings live in %LOCALAPPDATA%\NFL2K5-PC. The release only carries
  *.default.ini files, used when you have no settings yet.
- Saves are in the game folder's "saves" folder. Each save is kept twice:
  saves\<kind> (rosters, franchise, vip, settings) and saves\UDATA. Deleting
  a save in the game or from either place now removes it from both; the other
  copy is kept in saves\backups\deleted in case you want it back.
- Your own presentation packages: keep them in their own folder under
  mods\presentations (copy a shipped one to a new name before changing it).
  The update replaces only the packages it ships (CBS_2026, NBC_SNF,
  NFL on FOX, _runtime) and never deletes anything.


IF SOMETHING GOES WRONG
-----------------------
The game now shows a message instead of closing silently. If it crashes it
saves a crash report. Press Win+R, type  %LOCALAPPDATA%\NFL2K5-PC\logs  and
press Enter. Send:
- session.log (the log of the last start) and xbox_kernel.log (one folder up)
- crash-<date>.txt and crash-<date>.dmp, if there are any
- a screenshot or short video of what happened, and the exact text of any
  message
